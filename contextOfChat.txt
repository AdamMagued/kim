# Kim Project Context & Memory Dump
==================================================
Date: 2026-05-11

## Architecture Overview
- Kim is an agentic coding assistant running locally on macOS.
- **Frontend**: Tauri (Rust) + React (TypeScript/Tailwind CSS). The UI components include ChatView, SettingsPanel, ToolCallCard, etc.
- **Backend/Orchestrator**: Python-based orchestrator utilizing MCP (Model Context Protocol).
- **Core Engine**: `claw-code` (Rust), which is a port/continuation of an open-source tool, integrated to handle complex multi-step coding tasks natively.
- **Browser Bridge**: A unique system that proxies LLM API calls through the user's authenticated browser session (Gemini, Claude, DeepSeek, Grok) using Playwright. This allows Kim to operate without API keys by driving the web UI.

## Recent Issues & Resolutions
1. **"Prompt changed after injection" Error**:
   - *Cause*: Rich text editors in browsers (like Gemini) auto-format pasted text, converting straight quotes to smart quotes ("" -> “”), em-dashes, and ellipses. When the Python/Rust bridge tried to verify if the injected text matched the expected prompt, it failed the strict string comparison.
   - *Fix*: Implemented robust typography normalization in both `browser_provider.py` (Python) and `lib.rs` (Tauri). Added fuzzy matching for boundaries (ignoring non-word characters) so that if the length is >98% match, slight typography differences don't break the injection loop.

2. **Leaking JSON in Activity Feed**:
   - *Cause*: Sometimes the Browser LLM returns text that starts with `{"text": "` but the JSON is truncated or malformed, causing `json.loads` to fail. The bridge then printed the raw text string to `[STATUS]`, leading to `{"text": ...` appearing in the Kim UI.
   - *Fix*: Updated `_surface_bridge_reasoning` in `claw_bridge.py` with aggressive regex to strip leading `{"text": "` and trailing brackets before pushing to the activity feed, ensuring the reasoning reads naturally ("Kim is thinking...").

3. **Technical Noise ("Claw completed")**:
   - *Cause*: `run_claw_subtask` returned a technical success string showing relay counts and exit codes, which was surfaced to the user.
   - *Fix*: Replaced the technical log with a user-friendly "Task completed successfully." message.

4. **Game Implementations (Pong & Tower Drop)**:
   - Built a neon-styled CPU version of Pong with Easy/Medium/Hard difficulties in `pong.html`.
   - Created a dynamic multi-level physics simulation `tower_sim.html` where balls drop through rotating platforms with holes.

## Technical Details & Specifics
- `browser_provider.py`: Handles the Python side of Playwright injection. Relies on `_verify_injection`.
- `lib.rs`: Handles the JS-injected script execution for DOM manipulation. Relies on `normalizeText` and `promptMatchesInput`.
- `claw_bridge.py`: Acts as the translation layer between the Rust `claw-code` engine's `bridge_request.json` / `bridge_response.json` format and the browser's conversational format.
- The `ChatView.tsx` component handles log suppression using a list of `HIDDEN_SUBSTRINGS` to prevent system noise from cluttering the UI.
